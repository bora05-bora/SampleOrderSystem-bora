# PHASE 5 — 품질 완성 (안정성 · 사용성)

> **목표**: 잘못된 입력, 경계값, 빈 목록 등 예외 상황에서도 프로그램이 죽거나 데이터가 꼬이지 않도록 마무리한다. 화면 구성의 일관성도 정리하여 실제 사용 가능한 수준으로 완성한다.

---

## 구현 범위

### 1. 입력 유효성 검사

모든 입력 지점에서 아래 규칙을 적용합니다.

| 입력 항목 | 검사 규칙 | 오류 시 처리 |
|---------|---------|------------|
| 메뉴 번호 | 정수 범위 내 값 | 안내 메시지 출력 후 재입력 요청 |
| 시료 ID | 공백 불가, 중복 불가 | "이미 존재하는 ID입니다" 안내 |
| 이름 | 공백 불가 | "이름을 입력해 주세요" 안내 |
| 평균 생산시간 | 양수 실수 | "0보다 큰 값을 입력해 주세요" 안내 |
| 수율 | 0.0 초과 1.0 이하 | "0~1 사이의 값을 입력해 주세요" 안내 |
| 주문 수량 | 양의 정수 | "1 이상의 정수를 입력해 주세요" 안내 |
| 문자 입력 (숫자 필드) | 숫자가 아닌 입력 | "숫자를 입력해 주세요" 안내 후 재입력 |

### 2. 경계값 처리

| 상황 | 예상 동작 |
|------|---------|
| 재고 == 주문 수량 (딱 맞음) | 재고 충분으로 처리 → `Confirmed`, 재고 0으로 차감 |
| 재고 == 0, 주문 수량 1 | 부족분 1 → 실 생산량 = ceil(1 / (yield × 0.9)) |
| 수율 1.0 (100%) | `ceil(부족분 / 0.9)` 계산 정상 동작 확인 |
| 동일 시료에 여러 주문이 연달아 승인 | 각 주문 승인 시점의 재고를 기준으로 독립 판정 |

### 3. 빈 목록 상태 처리

| 화면 | 빈 상태 안내 |
|------|------------|
| 주문 승인/거절 | "처리 대기 중인 주문이 없습니다." |
| 생산라인 조회 | "현재 생산 중인 작업이 없습니다." |
| 출고 처리 | "출고 가능한 주문이 없습니다." |
| 시료 목록 | "등록된 시료가 없습니다." |
| 시료 검색 결과 | "검색 결과가 없습니다." |

### 4. 화면 구성 통일

모든 화면에 일관된 스타일을 적용합니다.

| 요소 | 규칙 |
|------|------|
| 구분선 | `====` (헤더) / `----` (항목 구분) 통일 |
| 상태 표시 | 콘솔 컬러 적용: Reserved(흰색), Producing(노랑), Confirmed(초록), Release(파랑), Rejected(회색) |
| 재고 상태 | 여유(초록), 부족(노랑), 고갈(빨강) |
| 숫자 정렬 | 우측 정렬, 단위(ea, min) 표기 통일 |
| 오류 메시지 | 빨간색으로 출력 |
| 성공 메시지 | 초록색으로 출력 |

### 5. 전체 시나리오 최종 검수

Phase 1~4의 모든 기능을 연속으로 수행하며 데이터 일관성을 검증합니다.

---

## 완료 조건 (Definition of Done)

- [ ] 모든 숫자 입력란에 문자를 입력해도 프로그램이 종료되지 않는다
- [ ] 음수·0 등 범위를 벗어난 값 입력 시 안내 메시지가 출력된다
- [ ] 재고 == 주문 수량인 경우 `Confirmed`로 처리되고 재고가 0이 된다
- [ ] 빈 목록 상태에서 각 화면 진입 시 적절한 안내 메시지가 출력된다
- [ ] 모든 화면의 구분선·색상·정렬이 일관되게 적용된다
- [ ] 연속으로 모든 기능을 반복 사용해도 데이터가 꼬이지 않는다

## 고객님 테스트 시나리오

> 이 Phase는 **시스템을 흔들어 보는** 테스트입니다. 일부러 잘못된 값을 넣어보세요.

### 입력 오류 테스트

| 테스트 | 입력 방법 | 기대 결과 |
|--------|---------|---------|
| 메뉴에 문자 입력 | 메인 메뉴에서 `abc` 입력 | 오류 안내 후 재입력 요청 |
| 수량에 음수 | 주문 수량에 `-5` 입력 | "1 이상의 정수를 입력해 주세요" |
| 수량에 0 | 주문 수량에 `0` 입력 | 같은 오류 안내 |
| 수율에 1 초과 | 시료 등록 시 수율 `1.5` 입력 | "0~1 사이의 값을 입력해 주세요" |
| 수량에 공백 | 엔터만 입력 | 오류 안내 후 재입력 요청 |

### 경계값 테스트

| 테스트 | 설정 방법 | 확인 포인트 |
|--------|---------|-----------|
| 재고 = 주문 수량 | 재고 50ea 시료에 50ea 주문 후 승인 | Confirmed, 재고 0 |
| 재고 0 전체 부족 | 재고 0 시료에 1ea 주문 후 승인 | Producing, 실 생산량 계산 확인 |

### 빈 목록 테스트

1. 아무 주문도 없는 상태에서 `[3] 주문 승인/거절` 진입 → 안내 메시지 확인
2. 생산 큐가 비어있을 때 `[4] 생산라인 조회` 진입 → 안내 메시지 확인
3. Confirmed 주문이 없을 때 `[6] 출고 처리` 진입 → 안내 메시지 확인

### 반복 사용 피로도 테스트

- 주문 접수 → 승인 → 생산 완료 → 출고 사이클을 5회 반복
- 매 사이클 후 모니터링에서 주문 건수·재고가 정확한지 확인
