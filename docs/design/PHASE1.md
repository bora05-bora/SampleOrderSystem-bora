# PHASE 1 — 프로젝트 기반 구축 + 시료 관리

> **목표**: 시스템을 처음 실행할 수 있는 상태로 만들고, 시료를 등록·조회·검색하는 기능을 완성한다.

---

## 구현 범위

### 1. 프로젝트 구조 생성

```
SampleOrderSystem/
├── SampleOrderSystem.sln
└── SampleOrderSystem/
    ├── SampleOrderSystem.vcxproj
    ├── include/
    │   └── nlohmann/json.hpp
    ├── src/
    │   ├── main.cpp
    │   ├── Models.h                  # SampleData 구조체
    │   ├── DataStore.h / .cpp        # samples.json 읽기/쓰기
    │   ├── SampleController.h / .cpp # 시료 관련 비즈니스 로직
    │   ├── SampleView.h / .cpp       # 시료 관련 화면 출력·입력
    │   └── MainController.h / .cpp   # 메인 메뉴 루프
    └── data/
        └── samples.json              # 자동 생성
```

### 2. 데이터 모델

```cpp
struct SampleData {
    std::string id;            // "01", "02", "03" (자동 부여)
    std::string name;          // "실리콘 웨이퍼-8인치"
    double productionTime;     // 0.5  (min/ea)
    double yield;              // 0.92
    int stock;                 // 480  (ea)
    // toJson(), fromJson()
};
```

### 3. samples.json 스키마

```json
{
  "nextId": 4,
  "samples": [
    {
      "id": "01",
      "name": "실리콘 웨이퍼-8인치",
      "productionTime": 0.5,
      "yield": 0.92,
      "stock": 480
    }
  ]
}
```

### 4. 메인 메뉴

- 시스템 현황 요약 표시 (등록 시료 수, 총 재고)
- 메뉴 항목: `[1] 시료 관리` / `[0] 종료`
- Phase 2~5 메뉴는 `(준비 중)` 표시
- 메뉴 항목 글자색은 모두 파란색으로 통일

### 5. 시료 관리 기능

| 기능 | 입력 | 동작 |
|------|------|------|
| 시료 등록 | 이름, 평균 생산시간, 수율 | ID는 자동 부여 (01, 02, 03…), 재고는 0으로 초기화 |
| 시료 목록 조회 | — | 전체 시료를 표 형식으로 출력, 재고 포함 |
| 시료 검색 | 이름 키워드 | 부분 일치 검색, 결과 없으면 안내 메시지 |

## 고객님 테스트 시나리오

> 프로그램을 빌드·실행한 뒤 아래 순서대로 진행해 주세요.

**Step 1 — 시료 3개 등록** (ID는 자동 부여, 입력 불필요)

| 자동 부여 ID | 이름 | 생산시간 | 수율 |
|-------------|------|---------|------|
| 01 | 실리콘 웨이퍼-8인치 | 0.5 | 0.92 |
| 02 | GaN 에피택셀-4인치 | 0.3 | 0.78 |
| 03 | SiC 파워기판-6인치 | 0.8 | 0.92 |

**Step 2 — 목록 조회** → 3개가 보이는지, ID가 01/02/03, 재고가 모두 0 ea인지 확인

**Step 3 — 검색** → "웨이퍼" 입력 시 ID 01 시료가 나오는지 확인

**Step 4 — 재시작** → 프로그램 종료 후 재실행 → 등록한 3개 시료가 그대로이고, 다음 등록 시 ID가 04부터 시작하는지 확인
