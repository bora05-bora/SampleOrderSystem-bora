# 기능 명세 — 시료 관리

## 개요

시료(Sample)는 시스템의 가장 기본 단위입니다. 시스템에 등록된 시료만 주문할 수 있습니다.

---

## 시료 속성

| 속성 | 설명 | 비고 |
|------|------|------|
| 시료 ID | 시료를 고유하게 식별하는 코드 | 예: S-001 |
| 이름 | 시료명 | 예: 실리콘 웨이퍼-8인치 |
| 평균 생산시간 | 시료 1개를 생산하는 데 걸리는 평균 시간 | 단위: min/ea |
| 수율 | 정상 시료 수 / 총 생산 시료 수 | 범위: 0.0 ~ 1.0, 예: 0.92 |
| 현재 재고 | 현재 보유 중인 시료 수량 | 단위: ea |

---

## 세부 기능

### 1. 시료 등록

새로운 시료를 시스템에 추가합니다.

- 입력값: 시료 ID, 이름, 평균 생산시간, 수율
- 이미 존재하는 시료 ID는 등록 불가
- 등록 후 재고는 0으로 초기화

### 2. 시료 목록 조회

등록된 모든 시료 목록을 표 형식으로 표시합니다.

- 표시 항목: 시료 ID, 시료명, 평균 생산시간, 수율, 현재 재고
- 시료가 많은 경우 페이지 단위로 표시 가능

**예시 출력 항목**

```
ID      시료명              평균 생산시간   수율    현재 재고
S-001   실리콘 웨이퍼-8인치   0.5 min/ea    0.92   480 ea
S-002   GaN 에피택셜-4인치   0.3 min/ea    0.78   220 ea
S-003   SiC 파워기판-6인치   0.8 min/ea    0.92   30 ea
```

### 3. 시료 검색

이름 등 속성을 기준으로 특정 시료를 검색합니다.

- 이름 부분 일치 검색 지원
- 검색 결과 없을 경우 안내 메시지 표시

---

## 관련 제약

- 시스템에 등록된 시료만 주문 접수 가능
- 시료 삭제 기능은 이번 범위에 포함되지 않음
