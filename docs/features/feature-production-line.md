# 기능 명세 — 생산라인

## 개요

생산라인은 재고가 부족한 주문이 승인될 때 자동으로 등록되는 생산 대기열입니다. 하나의 생산라인이 시료를 순차적으로(FIFO) 생산합니다.

---

## 생산라인 특성

- 단일 라인: 동시에 하나의 주문만 생산
- 스케줄링: FIFO (선입선출)
- 주문이 들어온 시료에 대해서만 생산

---

## 실 생산량 계산

재고 부족 시 수율과 공정 오차를 고려하여 실제 생산량을 산정합니다.

```
부족분     = 주문 수량 - 현재 재고
실 생산량  = ceil(부족분 / (수율 × 0.9))
총 생산시간 = 평균 생산시간 × 실 생산량
```

**예시**

- 주문 수량: 200ea, 현재 재고: 30ea, 수율: 0.92, 평균 생산시간: 0.8 min/ea
- 부족분: 170ea
- 실 생산량: ceil(170 / (0.92 × 0.9)) = ceil(170 / 0.828) = ceil(205.3) = 206ea
- 총 생산시간: 0.8 × 206 = 164.8 min ≈ 165 min

---

## 생산 완료 처리

생산이 완료되면 시스템이 자동으로 처리합니다.

1. 생산된 수량만큼 시료 재고에 추가
2. 주문 상태: **PRODUCING → CONFIRMED** 자동 전환
3. 다음 대기 주문이 있으면 생산 시작

---

## 화면 표시 항목

### 현재 생산 중 (처리 중인 주문)

- 주문번호, 시료명
- 주문 수량, 현재 재고, 부족분, 실 생산량
- 진행률(%), 완료 예정 시각

### 대기 중인 주문 (생산 큐)

FIFO 순서로 대기 중인 주문 목록을 표시합니다.

| 표시 항목 | 설명 |
|---------|------|
| 순서 | FIFO 대기 순번 |
| 주문번호 | 해당 주문의 주문번호 |
| 시료명 | 생산할 시료명 |
| 주문 수량 | 주문된 총 수량 |
| 부족분 | 생산이 필요한 수량 |
| 실 생산량 | 실제 생산할 수량 |
| 예상 완료 시각 | 예상 생산 완료 시각 |

**예시 출력 항목**

```
생산라인 1개 (단일 라인)  현재 상태: RUNNING

[현재 처리 중]
  주문번호  ORD-20260416-0038   시료: SiC 파워기판-6인치
  주문량    80 ea  재고 30 ea → 부족 50 ea → 실생산량 61 ea (수율 0.92 / 49 min)
  진행      72%  완료 예정 09:49

[대기 중인 주문 (FIFO 순)]
  순서  주문번호       시료              주문량    부족분   실생산량   예상완료
  1     ORD-0040    산화막 웨이퍼-SiO2  150 ea   150 ea   190 ea    11:43
  2     ORD-0043    SiC 파워기판-6인치  200 ea   170 ea   206 ea    14:28
```

---

## 관련 제약

- 생산라인 등록은 주문 승인 시 자동으로만 이루어짐 (수동 등록 없음)
- 생산 중 주문 취소 기능은 이번 범위에 포함되지 않음
