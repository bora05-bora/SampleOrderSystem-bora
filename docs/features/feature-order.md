# 기능 명세 — 시료 주문 (접수)

## 개요

고객이 시료를 요청하면 주문 담당자가 시스템에 주문을 접수합니다. 접수된 주문의 초기 상태는 **RESERVED**입니다.

---

## 입력값

| 입력 항목 | 설명 | 비고 |
|---------|------|------|
| 시료 ID | 주문할 시료의 ID | 시스템에 등록된 시료만 선택 가능 |
| 고객명 | 주문 고객 이름 또는 회사명 | |
| 주문 수량 | 요청 수량 | 단위: ea, 1 이상 |

---

## 처리 흐름

1. 담당자가 시료 ID, 고객명, 주문 수량을 입력
2. 입력 내용 확인 화면 표시 (시료명, 고객, 수량)
3. 담당자가 예약 접수 여부 최종 확인 (Y/N)
4. 확인 시 주문 생성 → 상태: **RESERVED**
5. 주문번호 발급 및 현재 상태 출력

---

## 출력 정보

주문 접수 완료 후 표시되는 정보:

- 주문번호 (예: ORD-20260416-0043)
- 현재 상태: RESERVED
- 재고 확인은 승인 메뉴에서 진행한다는 안내

---

## 관련 제약

- 시스템에 등록되지 않은 시료 ID로는 주문 불가
- 주문 수량은 1 이상이어야 함
- 접수 단계에서는 재고를 차감하거나 생산라인에 등록하지 않음
- 접수 후 승인/거절은 별도 메뉴([주문 승인/거절](feature-order-approval.md))에서 처리
