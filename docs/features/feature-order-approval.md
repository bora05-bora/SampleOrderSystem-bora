# 기능 명세 — 주문 승인/거절

## 개요

생산 담당자가 RESERVED 상태의 주문을 검토하여 승인하거나 거절합니다. 승인 시 재고 상황에 따라 주문 상태가 자동으로 분기됩니다.

---

## 접수된 주문 목록

- RESERVED 상태의 주문만 표시
- 표시 항목: 번호, 주문번호, 고객명, 시료명, 주문 수량, 상태

---

## 주문 승인

RESERVED 주문을 선택하여 승인하면, 시스템이 재고를 확인한 후 자동으로 두 가지 경로 중 하나로 처리합니다.

### 경로 1 — 재고 충분

- 조건: 현재 재고 ≥ 주문 수량
- 처리: 주문 상태를 즉시 **CONFIRMED**로 전환
- 재고에서 주문 수량만큼 차감

### 경로 2 — 재고 부족

- 조건: 현재 재고 < 주문 수량
- 처리:
  1. 부족분 계산: `부족분 = 주문 수량 - 현재 재고`
  2. 실 생산량 계산: `ceil(부족분 / (수율 × 0.9))`
  3. 총 생산 시간 계산: `평균 생산시간 × 실 생산량`
  4. 생산라인 대기열(FIFO)에 자동 등록
  5. 주문 상태를 **PRODUCING**으로 전환
- 승인 시 부족분, 실 생산량, 예상 생산 시간을 담당자에게 안내 후 최종 확인 요청

---

## 주문 거절

RESERVED 주문을 선택하여 거절하면 즉시 **REJECTED** 상태로 전환됩니다.

- 거절된 주문은 모니터링에서 제외
- 거절 후 상태 복원 불가

---

## 상태 전환 정리

```
RESERVED → (승인 + 재고 충분)  → CONFIRMED
RESERVED → (승인 + 재고 부족)  → PRODUCING
RESERVED → (거절)             → REJECTED
```

---

## 관련 제약

- 승인/거절 대상은 RESERVED 상태의 주문만 해당
- 이미 PRODUCING, CONFIRMED, RELEASE, REJECTED 상태인 주문은 재처리 불가
- 재고 확인 및 생산라인 등록은 승인 시점에 자동 수행 (수동 입력 없음)
