# 기능 명세 — 모니터링

## 개요

담당자가 현재 시스템 상태를 한눈에 파악할 수 있도록 주문 현황과 재고 현황을 제공합니다.

---

## 서브 메뉴 구성

| 메뉴 | 설명 |
|------|------|
| 주문량 확인 | 현재 상태별 주문 건수 조회 |
| 재고량 확인 | 시료별 현재 재고 수량 및 재고 상태 조회 |

---

## 1. 주문량 확인

현재 상태별 주문 건수를 표시합니다.

- 포함 상태: RESERVED, PRODUCING, CONFIRMED, RELEASE
- **REJECTED는 유효한 주문이 아니므로 제외**

**예시 출력 항목**

```
상태별 주문 현황
  RESERVED    3건
  CONFIRMED   8건
  PRODUCING   3건  ← 생산라인 대기
  RELEASE    18건
```

---

## 2. 재고량 확인

각 시료별 현재 재고 수량과 재고 상태를 표시합니다.

### 재고 상태 기준

| 상태 | 조건 |
|------|------|
| 여유 | 주문 대비 재고가 충분한 상태 |
| 부족 | 주문 대비 재고 수량이 부족한 상태 |
| 고갈 | 재고 수량이 0인 상태 |

**예시 출력 항목**

```
시료명              재고       상태    잔여율
실리콘 웨이퍼-8인치  480 ea    여유    80%
GaN 에피택셀-4인치  220 ea    여유    44%
SiC 파워기판-6인치   30 ea    부족     6%
산화막 웨이퍼-SiO2    0 ea    고갈     0%
```

---

## 관련 제약

- REJECTED 주문은 주문량 집계에서 제외
- 재고 상태(여유/부족/고갈) 기준은 현재 CONFIRMED·RESERVED 주문량과 비교
